(async) download() → {Promise}

Description:

  • 下載伺服器指定檔案至本機

    先寫入下載暫存區(opt.fdDownloadTemp)內本次專用之暫存檔(<檔名>.<行程id>.<隨機碼>.part，以排他方式建立，同一暫存區由多個實例共用或遠端檔名相同皆不相撞)， 傳輸成功結束且本地大小等於遠端大小才移至fpLocal(取代舊檔)；與fpLocal同一磁碟時以改名一步取代，跨磁碟時先複製至fpLocal同資料夾之暫存名(<檔名>.<行程id>.<隨機碼>.part)再於同資料夾內改名；檔名超過150位元組者，暫存名中之檔名基底以碼點截短(使暫存名不超過255位元組)； 遠端大小無法取得(FTP之SIZE指令失敗)時無從核對是否下載完整，直接reject(can not get the size of file[fpRemote])而不傳輸；fpLocal為既有資料夾時於傳輸前即reject(ftpDownload: fpLocal is a directory, fpLocal is not changed)；改名遇占用(EPERM、EBUSY、EACCES，Windows下常為防毒掃描)時最多嘗試5次(每次失敗後等待200毫秒乘嘗試次數)，用盡仍失敗即刪除暫存檔並reject。 暫存區內逾24小時未更新、符合上述暫存檔名格式、行程id對應之行程已不存在者(本行程與他行程仍存在者皆不清)，視為崩潰殘留，由本行程於首次使用該暫存區時清除(之後同一行程最多每小時清一次)；不符格式之檔不動。 傳輸失敗(含連線中斷)、逾時、大小不符或無法移動時，刪除暫存檔並reject，fpLocal之舊檔不動(不存在者仍不存在)。 逾時自傳輸開始起計(WFtp之opt.timeLimit，預設60000毫秒，SFTP自本版起亦受其約束，大檔須自行給較大值)，到時即reject(訊息ftpDownload timeout[timeLimit])並刪除暫存檔名；SFTP查詢遠端檔案資訊之階段亦另受同一timeLimit約束，伺服器於該階段停滯時同樣逾時；FTP會中止傳輸，SFTP無法中止而可能於背景續行，其結束時只刪除暫存檔、不移至fpLocal(quit斷線後背景傳輸可能不再結束，暫存檔名已於逾時時刪除)；暫存檔名每次唯一，故逾時後可直接重試，或quit再conn重試同一檔。

(async) downloadViaTemp(o) → {Promise}

Description:

  • 下載單一檔案之共用流程(SFTP與FTP共用, 單一擁有者): 先寫入暫存區之本次專用暫存檔, 傳輸成功結束且本地大小等於遠端大小才移至fpLocal; 失敗、逾時、大小不符皆刪除暫存檔並reject, fpLocal之舊檔不動

    逾時: 自傳輸開始起計時timeLimit毫秒, 到時即reject(ftpDownload timeout[timeLimit]), 並呼叫傳輸端登記之中止函數(FTP為銷毀數據socket; SFTP無法中止, 傳輸可能於背景續行), 其後傳輸結束時一律只刪暫存檔、不移至fpLocal; 暫存檔名每次唯一, 故逾時後重試同一檔不與背景傳輸相撞

    opt.onTrace事件(type): 'sweep'({ removed })、'temp'({ act: 'create'|'remove', ok })、'timeout'({ timeLimit, stage })、'transfer'({ ok, late })、'verify'({ ok, size, sizeRemote })、'retry'({ n, code })、'move'({ mode: 'rename'|'copy' }); 逾時後之'transfer'(late為true)與'temp'(act為'remove')於promise已reject後才發生, 供得知背景傳輸已結束且暫存檔已清

withTimeLimit(o) → {Promise}

Description:

  • 為單一階段加上逾時: 到時即reject(ftpDownload timeout[timeLimit]), 階段先結束則清除計時器並照其結果結束; 逾時後該階段之結果不再採用

    供下載流程中不經暫存檔之階段(如SFTP查詢遠端檔案資訊)使用, 使伺服器於該階段停滯時不致永不結束; 逾時發出觀察事件'timeout'({ timeLimit, stage })
